CÓMO ABRIR
1. Mantené exactamente esta estructura de carpetas.
2. Abrí index.html con Chrome, Edge, Firefox o cualquier navegador moderno.
3. No hace falta servidor, JavaScript ni conexión a Internet, siempre que las imágenes locales estén colocadas en la carpeta imágenes.
